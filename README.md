# Super Repo de Hardening

Repositório consolidado para audits, baselines, shell scripts, Ansible/AWX,
IAC, dashboards e utilitários de hardening.

## Fonte oficial

O conteúdo atual vem de `HARDENING_CLARO_2026_S2-agosto_2026`.

- `audits/`: audits oficiais.
- `baselines/`: baselines oficiais.
- `automation/current/`: automação shell e Ansible/AWX atual.
- `tools/current/`: utilitários atuais.
- `reference-docs/current/`: documentação operacional.
- `poc/current/`: provas de conceito.
- `results/current/`: resultados mantidos como referência.

As fontes originais permanecem intactas durante a consolidação. As regras e o
inventário estão documentados em `docs/MERGE_POLICY.md`.
